# Cleanup Log

This file documents stale or duplicate outputs removed during final submission preparation.
All deleted artefacts were either (i) from earlier intermediate experiments that no longer
match the final pipeline, (ii) computed on a different universe than the final notebook, or
(iii) generated by an older variant of the project layout.

## Files removed

| Path | Reason |
| --- | --- |
| `outputs/risk_vs_carbon.png` | Stale figure from an early exploratory analysis; not produced by the final pipeline and not referenced in the final notebook. |
| `outputs/filtered_pacific_companies.csv` | Stale Part-1 filtering dump from an older eligibility procedure (one-shot). The final pipeline filters per-rebalance inside the rolling loop, so this static dump is no longer meaningful. |
| `outputs/part1_universe_filter_summary.csv` | Stale Part-1 summary from an older filtering pass; superseded by the in-loop eligibility logic of the final pipeline. |
| `outputs/portfolio_summary_stats.csv` | Stale top-level summary file; superseded by `outputs/tables/part3_summary_*` and `outputs/tables/part4_summary_*` produced by the final pipeline. |
| `outputs/figures/vw_portfolio_cumulative.png` | Stale Part-2 figure computed on a *different universe* than the final notebook. Its terminal cumulative value (~2.45) does not match the final VW path (terminal ~2.18) because that figure used the broader returns-eligible universe, while Part 3/4 are restricted to firms with valid Scope-1 emissions, revenues and market cap. To avoid showing two inconsistent VW cumulative paths, this image is regenerated inside the final notebook as `part2_cumulative_vw.png`. |
| `src/SAAM_Project.ipynb` | Older variant of the project notebook, superseded by `SAAM_Project_FINAL.ipynb`. |
| `src/__pycache__/` | Python bytecode cache; not a deliverable. |
| `src/.ipynb_checkpoints/` | Jupyter checkpoint cache; not a deliverable. |
| `src/MVP-construction.ipynb` | Standalone Part-1 notebook that produced a minimum-variance portfolio on the **returns-eligible universe** (493–498 firms). Its summary statistics — annualized return 4.08%, Sharpe ratio 0.16, cumulative return 61.65% — are not consistent with the final notebook (which restricts the universe to carbon-eligible firms and reports Sharpe 0.5654 / cumret 160.32%). Same rationale as `MVP-construction.ipynb`: numbers do not match the carbon-eligible universe used in Parts III and IV. | `outputs/tables/mv_weights.csv` | Standalone Part-1 MV weights computed on the returns-eligible universe; not the universe used in Parts III and IV. Replaced by the `mv` rows of `outputs/tables/part3_weights_mv_carbon50.csv` (carbon-eligible universe), produced by `src/05_part3.py`. |
