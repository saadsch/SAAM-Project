# Part 3 & Part 4 - Validation checklist

All checks below are verified against the outputs generated by
`python src/05_part3.py` and `python src/06_part4.py`.

## Weights

- [x] Every yearly weight vector sums to 1 within 1e-9.
  Verified by `solve_qp` (explicit equality constraint) and the post-solve
  `w = w / w.sum()` normalisation in `src/saam_core.py:357-359`.
- [x] No negative weights. Bounds `(0, 1)` applied per asset; result is
  clipped to >= 0 then re-normalised.
- [x] No NaN weights. Eligibility filter (`build_year_inputs`) drops firms
  without prices / cap / revenue / emissions before SLSQP runs.

## Optimiser status

- [x] Optimiser success per year and per strategy reported in
  `outputs/tables/part3_constraint_slack_*.csv` (`optimization_success`
  column) and `outputs/tables/part4_constraint_slack_vw_netzero.csv`.
- [x] Part 3: 60 / 60 solves successful (12 years x 5 portfolios).
- [x] Part 4: 24 / 24 solves successful (12 years x 2 portfolios incl.
  `vw_drift`).

## Carbon constraints

- [x] Part 3.2 uses `CF <= 0.5 * CF(P_mv_oos)` per year (NOT VW).
  Implemented at `src/05_part3.py:127`.
- [x] Part 3.3 uses `CF <= 0.5 * CF(P_vw)` per year.
  Implemented at `src/05_part3.py:140`.
- [x] Part 4 anchors `CF(P_vw)_2013` ONCE (computed at
  `src/06_part4.py:78`); cap is
  `(1 - 0.10)^(Y - 2013 + 1) * anchor` and is NOT recomputed each year.
- [x] All carbon constraints satisfied within 1e-6.
  Worst slack across all strategies is ~-1.4e-14 (numerical noise of SLSQP).
- [x] Carbon constraint slack column emitted per year per strategy.
  Files: `part3_constraint_slack_mv_carbon50.csv`,
  `part3_constraint_slack_vw_carbon50.csv`,
  `part4_constraint_slack_vw_netzero.csv`,
  `part4_netzero_target_vs_realized_cf.csv`.

## Tracking error

- [x] Annualised TE computed as
  `sqrt((alpha - alpha_vw)' Sigma_monthly (alpha - alpha_vw)) * sqrt(12)`,
  per `src/05_part3.py:189` and `src/06_part4.py:155`.
- [x] Ex-post TE (annualised std of `R_p - R_vw`) reported in the same
  files alongside the ex-ante figure.

## Units

- [x] Revenues divided by 1000 before computing CI -> CI in tCO2e per
  USD-million revenue (`src/saam_core.py:266`).
- [x] Market cap in USD millions (DS_MV_T_USD_*) before computing
  `CF_per_w = E / Cap` -> CF in tCO2e per USD-million invested
  (`src/saam_core.py:267`).
- [x] All tables and figures label WACI as
  `tCO2e per USD-million revenue` and CF as
  `tCO2e per USD-million invested`.

## Returns and performance

- [x] Monthly returns (`final_returns_matrix.csv` style) used for all
  performance.
- [x] Annual rebalancing respected: weights computed once at end-Y,
  drifted through year Y+1 (`simulate_year`, `src/saam_core.py:372-389`).
- [x] Cumulative-return plots start at $1: an extra row of 1.0 is
  prepended one month before the first OOS return in `plot_cumulative`
  (`src/saam_core.py:448-464`).

## Look-ahead bias

- [x] Every end-of-year decision uses the 120-month window ending in
  December of year Y. No data from year Y+1 enters covariance, eligibility
  or carbon constraints.
- [x] The VW benchmark (`vw_monthly_rebalanced`) uses `cap.shift(1)` so
  next-month return is weighted by prior-month cap shares
  (`src/saam_core.py:392-399`).
- [x] The Part 4 anchor uses end-2013 information only, applied
  multiplicatively forward.

## Cross-section consistency

- [x] The eligible universe is computed identically in both scripts
  (single `build_year_inputs` in `saam_core.py`).
- [x] Part 3 emits a cached VW(-50%) monthly + annual file
